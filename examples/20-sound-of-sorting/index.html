Inspired by the classic "Sound of Sorting" and "Radix Sort Redux" demonstrations.

Algorithm State Data Domain Audio Output Transformation Function & Auditory Logic
Array Element Value 1 to N ($N = 40$) Pitch: C3 ➔ C6 scalePitch().domain([1, N]).range(['C3','C6']) — Higher array values sound in high registers; sorted arrays produce smooth rising scales.

Swap / Write Event $\text{swap}(A[i], A[j])$ Percussive Click Acoustic transient click confirming in-place array mutation.
