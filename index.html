📜 Principles of Data Sonification

Derived from research and practice in data musicology (including Daniel Muldrew's "Transforming Data Into Music"):

1. Mapping Data to Sound

Data + Known Mapping = Meaning
Data + Cryptic Mapping = Noise / Junk

Just as an unlabeled visual chart causes confusion, sonification without an explicit audio legend is mere noise. Every `d3-audio` demo provides an interactive `audioLegend()` key so listeners know what each sound signifies.

2. The "Stay Close to the Data" Rule

"Stay close to the data... otherwise it's art!"

Artistic sonification permits arbitrary aesthetic liberties. Analytical sonification demands mathematical faithfulness: ratios, deltas, and taxonomies must be preserved so a listener can reconstruct the data from the sound.

Continuous vs. Ordinal vs. Categorical Data

Data Variable Type Visual Attribute Auditory Attribute (`d3-audio`) Recommended Scaler
Continuous Quantitative Position (X, Y), Length Frequency / Pitch / Cutoff / Pan scalePitch().quantize(false), scaleFilter(), scalePan()
Ordinal (Ranked Hierarchy) Step Rank, Severity Level Diatonic Scale Degrees, Octaves, Tension scalePitch().quantize(true), scaleTension()
Categorical (Unranked Classes) Color Hue, Pattern Texture Instrument Timbre, Percussion Samples, Mode scaleSample(), distinct Synth Models, Modal Keys

📚 Searchable API Quick-Reference & Cheat Sheet

Filter and search across all `d3-audio` constructors, scalers, and choreography methods. Click "Copy Snippet" to grab production-ready code.

scalePitch() Scalers

Maps quantitative domain values to quantized musical pitch note strings (e.g. "C4", "G#5") or continuous Hz frequencies.

const pitch = scalePitch() .domain([0, 100]) .range(["C3", "C6"]) .scale("pentatonic") .root("C");
scaleGain() Scalers

Maps quantitative metrics to audio amplitude velocity [0.0, 1.0] or decibel gain [-60dB, 0dB] with linear or exponential curves.

const gain = scaleGain() .domain([0, 1000]) .range([0.2, 0.9]) .curve("exponential");
scalePan() Scalers

Maps horizontal spatial positions (e.g. SVG X coordinates, longitude) to stereo panning [-1.0 Left, +1.0 Right].

const pan = scalePan() .domain([0, 800]) .range([-0.9, 0.9]);
scaleFilter() Scalers

Maps continuous telemetry to lowpass or highpass filter cutoff frequencies in Hertz (e.g. 200 Hz muffled to 8000 Hz bright).

const filter = scaleFilter() .domain([0, 100]) .range([400, 8000]);
scaleTension() Scalers

Multi-dimensional volatility scaler coordinating risk into chord harmony (Major to Tritone), filter cutoff, and tempo multipliers.

const tension = scaleTension().domain([0, 100]); const { chord, filterCutoff, tempoMultiplier } = tension(85);
scaleDuration() Scalers

Maps data magnitude to musical note durations (e.g. '16n', '8n', '4n', '1m') or absolute gate lengths in seconds.

const dur = scaleDuration() .domain([0, 50]) .range([0.1, 1.2]);
scaleSample() Scalers

Maps discrete categorical classes to percussion drum samples ('kick', 'snare', 'hihat', 'clap', 'bell', 'blip') or custom WAV/MP3s.

const sample = scaleSample() .domain(["login", "error", "success"]) .range(["blip", "snare", "bell"]);
choreography() Choreography

Applies frame-synchronized kinetic screen animations ('wiggle', 'flip', 'pulse', 'bounce', 'shake', 'ripple', 'glow', 'squash') to SVG/DOM selections.

const choreo = choreography() .movement("wiggle") .intensity(1.5) .duration(0.4); d3.select(element).call(choreo);
audioLegend() UI & Legends

Mounts an accessible interactive audio key onto any D3 container with interactive 🔊 audition buttons for pitch, volume, pan, and tension.

const legend = audioLegend() .title("Chart Audio Key") .pitch(pitchScale, "Metric Value") .pan(panScale, "X Position"); d3.select("#legend-mount").call(legend);
timeline() Timeline

Conductor coordinating multi-track Tone.js scheduling, loop repetition, BPM control, and synchronized element choreography.

const tl = timeline({ bpm: 120, loop: true }) .data(dataset) .time((d, i) => i * 0.25) .pitch(d => pitch(d.val)) .movement(d => ({ movement: "pulse", element: d.node })); await tl.play();
createSynth() Audio & Synths

Factory instantiating production-ready Tone.js synthesizers ('polySynth', 'fmSynth', 'amSynth', 'membraneSynth', 'pluckSynth') with built-in filters & pan.

const synth = createSynth({ type: "polySynth", volume: -4, pan: 0.0 });
createSamplePlayer() Audio & Synths

Synthesizer & sampler playing zero-asset offline percussion drum models or loading external WAV/MP3 asset URLs into memory buffers.

const player = createSamplePlayer(); player.trigger("kick", "8n"); await player.loadUrls({ click: "/click.wav" });
defaultEngine Audio & Synths

Singleton Web Audio manager that safely resumes the browser audio context on user gestures and provides master gain & limiter protection.

await defaultEngine.start(); console.log("Audio Context state:", defaultEngine.state);
scaleUncertainty() Scalers

Maps statistical uncertainty, p-values, or error margins to Tone.BitCrusher bit reduction (16 to 2 bits) and lo-fi saturation grit.

const uncertainty = scaleUncertainty() .domain([0, 1]) // 0 = certain, 1 = uncertain .range([16, 2]); // bits const { bits, grit, wet } = uncertainty(pValue);
scaleSpatial() Scalers

Maps 3D Z-depth, epicenter distance, or cluster hierarchy to reverberant acoustic space (wet/dry decay and spatial pre-delay).

const spatial = scaleSpatial().domain([0, 100]); const { wet, decay } = spatial(zDistance);
scaleEcho() Scalers

Maps moving-average windows, network latency, or memory inertia to Tone.FeedbackDelay parameters.

const echo = scaleEcho().domain([0, 1000]); const { delayTime, feedback } = echo(latencyMs);
scaleChord() Scalers

Multivariate harmonic scaler converting multidimensional data records into voiced chords (triads, 7ths, 9ths, sus, dim) with inversion and drop-2 voicing.

const chord = scaleChord(); const { notes, frequencies } = chord({ root: "C3", quality: "maj7", voicing: "open" });
scaleRhythm() Scalers

Computes Euclidean rhythms using the Bjorklund algorithm, mapping continuous data density into polyrhythmic patterns and Tone.js timing offsets.

const rhythm = scaleRhythm().domain([0, 100]).steps(16); const { pattern, events } = rhythm(activityLevel);
audioTransition() Choreography

Direct D3 transition bridge ramping audio parameters (frequency glissando, volume fades, filter sweeps) synchronized with SVG visual animations.

d3.select(".dot") .transition() .duration(800) .attr("cy", y(val)) .call(audioTransition(synth, { frequency: pitch(val) }));
createGranularScrubber() Audio & Synths

Tone.GrainPlayer wrapper enabling click-free, pitch-stable micro-grain scrubbing across continuous telemetry charts or audio buffers.

const scrubber = createGranularScrubber(); scrubber.start(); scrubber.scrub(normalizedX); // 0.0 to 1.0
accessibleChart() UI & Legends

Turnkey D3 accessible (a11y) sonifier component providing keyboard arrow navigation, screen-reader ARIA live updates, and min/max earcons.

d3.select("#chart-container").call(accessibleChart({ data: dataset, x: d => d.date, y: d => d.value }));

🚀 Quickstart Integration

`d3-audio` is distributed as a lightweight UMD bundle and ES module. Include D3, Tone.js, and `d3-audio` in your HTML:

<!-- Load dependencies and d3-audio bundle --> <script src="https://cdn.jsdelivr.net/npm/d3@7"></script> <script src="https://cdnjs.cloudflare.com/ajax/libs/tone/14.8.49/Tone.js"></script> <script src="./dist/d3-audio.js"></script> <script type="module"> import { scalePitch, scaleGain, scalePan, scaleTension, audioLegend, timeline, choreography } from "./src/index.js"; // 1. Define D3-style audio scalers const pitchScale = scalePitch() .domain([0, 100]) .range(["C3", "C6"]) .scale("pentatonic"); const panScale = scalePan().domain([0, 800]).range([-0.9, 0.9]); const tensionScale = scaleTension().domain([0, 100]); // 2. Mount Interactive Audio Legend const legend = audioLegend() .title("Chart Audio Key") .pitch(pitchScale, "Metric Value (0 ➔ 100)") .pan(panScale, "Horizontal X Position") .tension(tensionScale, "Volatility Risk Alert"); d3.select("#legend-mount").call(legend); // 3. Play frame-synchronized audio & screen choreography const tl = timeline({ bpm: 120, loop: true }) .data(dataset) .pitch(d => pitchScale(d.value)) .pan(d => panScale(d.x)) .movement(d => ({ movement: "wiggle", intensity: 1.2, element: d.node })); await tl.play(); </script>
